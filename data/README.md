# Data directory

The competition files are deliberately excluded from Git. Download them from
the Kaggle Store Sales competition after accepting its rules, then place them
in `data/raw/`:

```text
data/raw/
├── holidays_events.csv
├── oil.csv
├── sample_submission.csv
├── stores.csv
├── test.csv
├── train.csv
└── transactions.csv
```

The pipeline validates filenames, columns, keys, dates, the 16-day test horizon,
and store-family coverage before writing artifacts.

`data/synthetic/` is generated by `make smoke`. It imitates only the CSV schema
and key relationships. It contains no competition observations and must not be
used for model comparison or reported results.
